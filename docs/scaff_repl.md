## 5. Scaffold Replacement

**Example:** `examples/scaff_repl_run.ipynb`

Given the SMILES of the entire molecule and the SMILES of the scaffold that needs to be replaced, the code screens the fragment library to identify potential replacement scaffolds.

The following steps are used to shortlist and rank potential candidates:

1. **Initial shortlisting:** Identifies fragments with heavy atom counts within -20% to +50% of the reference scaffold and having the same number of attachment points.

2. **Attachment point distance filtering:** Further screens the shortlisted fragments based on the bond distances between their attachment points. Only fragments with distances within the permitted ranges relative to those of the reference scaffold are retained.

3. **Attachment point mapping:** Maps the attachment points between the reference scaffold and the candidate fragments by comparing the ECFP4 fingerprints around each attachment point and selecting the most similar mapping.

4. **Similarity-based ranking:** Calculates a combined score using USRCAT similarity, ECFP4-based Tanimoto similarity and physicochemical property similarity (depending on the `sim_mode` selected by the user). The top `N` scaffolds are then shortlisted based on this score.

### Inputs

- `whole_smiles`: SMILES of the entire molecule.
- `scaffold_smiles`: SMILES of the scaffold that needs to be replaced.
- `top_n`: Number of replacement scaffolds to shortlist after ranking.
- `resources`: Fragment library dictionary containing the USRCAT fingerprints, attachment site fingerprints, physicochemical properties and other precomputed information required for screening.
- `sim_mode`: Determines the type of physicochemical similarity calculation used. Options: `"desc"` / `"ecfp4"`.
- `output_dir`: Directory where the outputs are stored.

### Execution Modes

The main functionality is available through two functions:

- `run_scaff_repl()`: Used when performing scaffold replacement for a single molecule.
- `run_scaff_repl_batch()`: Used when performing scaffold replacement for multiple molecules sharing the same scaffold. This function additionally supports multiprocessing to speed up the replacement process. By default, it uses 4 fewer CPU cores than the total number available.

### Fragment Library

The fragment library is generated by performing BRICS fragmentation on approximately 2 million ChEMBL molecules available through TDC.

The resulting fragments are further processed to remove:
- Molecules containing PAINS substructures.
- Molecules containing Brenk structural alerts.
- Inorganic molecules.
- Molecules containing metals.

The library also stores precomputed information such as USRCAT fingerprints, attachment site fingerprints and physicochemical properties, which are used during the screening and ranking process.
